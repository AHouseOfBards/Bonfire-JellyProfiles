# Library Artwork

Jellyfin picks a library's tile picture from what's inside it, so a Kids profile can see
a Movies tile showing a film it can't open.

To fix that, open **Edit Profile** and turn on **Choose the artwork on each library
tile**. For each library, pick:

- **Default:** Jellyfin's own picture.
- **Picture:** an image you choose.
- **Hidden:** just the icon and the name.

This only applies in apps where Bonfire runs. The swap happens in the browser, so the
original picture is still downloaded.
