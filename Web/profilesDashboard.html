⚠️ Client Script Auto-Injection Failed The plugin was unable to automatically modify Jellyfin's index.html. Without this script, the "Who's Watching?" profile gate and switcher will not load.

How to fix: Run the command for your platform, then click Re-check Now below — no Jellyfin restart needed.
Jellyfin is running as , and the command below grants access to exactly that account.
  • Linux (Native):
    sudo chown jellyfin:jellyfin /usr/share/jellyfin/web/index.html
    sudo chmod 664 /usr/share/jellyfin/web/index.html
    After Jellyfin restarts and injects the script, you can optionally restore the original permissions with chmod 644.
  • Docker (Run on host):
    docker exec -u root <container-name> chown jellyfin:jellyfin /jellyfin/jellyfin-web/index.html
    docker exec -u root <container-name> chmod 664 /jellyfin/jellyfin-web/index.html
  • Windows (Admin Command Prompt):
    icacls "C:\Program Files\Jellyfin\Server\jellyfin-web\index.html" /grant "Users:(M)" /grant "NT AUTHORITY\NetworkService:(M)"
