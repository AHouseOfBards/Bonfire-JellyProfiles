Common problems

The switcher doesn't appear

Restart Jellyfin after installing or updating Bonfire: the old version runs until the server process restarts. On Docker, restart the container; the dashboard's Restart button often doesn't.

An index.html with no Bonfire tag in it is normal. Bonfire adds its script as the page is served.

It works in a browser but not in an app

Only clients that load Jellyfin's web page from your server show the switcher. For other clients, turn on sign-in with a PIN under Clients. Parental controls apply in every client either way.

A profile's library access keeps reverting

Change a profile's libraries in "Edit profile", not in Dashboard → Users. Adding one there sticks; removing one doesn't, because it looks the same as Jellyfin resetting the account.

Libraries other plugins manage, like FieldGuide's, aren't listed or changed.

Someone forgot their PIN

Clear it under Households. The account can then set a new one.

Bonfire is in the way and I can't get in

Enter the emergency disable code on any Bonfire screen, or press Ctrl+Shift+B. If neither works, or the script doesn't load at all, restart Jellyfin.
